# MCP Trust Levels

> **Superseded for tier assignment** by [`trust-tiers.md`](trust-tiers.md), which maps these
> levels onto the `ai-architect` field guide's T0–T3 provenance scale and the CoE's risk tiers.
> This file still defines what each MCP level technically permits — start a new tool assignment
> from `trust-tiers.md`, not from here.

## Level 0: Blocked
No access to MCP tools.

## Level 1: Read-only
Can inspect docs, metrics, and non-sensitive resources.

## Level 2: Limited write
Can update low-risk artifacts with approval gates.

## Level 3: Operational write
Can execute production-adjacent actions with guardrails and logging.

## Level 4: Privileged
Restricted emergency access, short-lived, fully audited.
